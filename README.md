## 当前项目

### 🧪 元素周期表 (`mushroom.cpp`)

一份完整的 **118 个化学元素** 数据表，使用 C++ 结构化存储，支持编译运行并打印全表。

```
元素数量: 118 个（第1周期 ~ 第7周期，含镧系和锕系）
数据结构: Element { 原子序数, 符号, 中文名, 英文名, 原子量, 分类 }
```

**运行：**

```bash
g++ -std=c++17 mushroom.cpp -o mushroom && ./mushroom
```

**前 20 号元素速记口诀：**

```
氢氦锂铍硼    碳氮氧氟氖
钠镁铝硅磷    硫氯氩钾钙

H  He Li Be B     C  N  O  F  Ne
Na Mg Al Si P     S  Cl Ar K  Ca
```
